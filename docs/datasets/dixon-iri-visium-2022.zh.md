# Dixon 2022 · 小鼠肾损伤的空间时间序列

> 和 Kirita 2020 同类的损伤到修复过程，用 Visium 测的空间图谱：检查模型从单核数据预测出的变化，在空间上是否出现。

**物种** 小鼠 · **测法** 空间 · **获取** 公开

## 一眼看完

| | |
|---|---|
| 规模 | 5 张 Visium 切片 |
| 人 / 样本 | 每个时间点一只雌鼠：假手术、4 小时、12 小时、2 天、6 周（GEO 样本名） |
| 标签 | 缺血再灌注损伤后的时间 |
| 许可 | GEO: not stated |
| 论文 | Dixon EE et al. J Am Soc Nephrol 2022;33:279–289. doi:10.1681/ASN.2021081150 |

## 测了什么

损伤到修复全过程的 10x Visium 空间基因表达，用 Giotto 和 SPOTlight 分析；作者报告受损近端小管和巨噬细胞、淋巴细胞的相互作用一直增加到 6 周（GEO 摘要）。

## 已知问题

- 每个时间点只有一张切片，没有重复：只能当正交证据，不能当做统计检验的测试集。
- 是雌鼠，缺血时间也和 Kirita 2020 不同，两者不是同一批动物。
