# Abedini 2024 · 大鼠高血压肾损伤和盐皮质激素受体拮抗剂

> 用 finerenone 或螺内酯处理的大鼠肾：给“盐皮质激素受体拮抗”这类假设提供实测答案；临床试验已经显示，这类药能保护 2 型糖尿病合并 CKD 病人的肾。

**物种** 大鼠 · **测法** 单核 RNA · ATAC · **获取** 公开

## 一眼看完

| | |
|---|---|
| 规模 | 22 个单核 RNA 样本（310,218 个核）；9 个 snATAC 样本（53,298 个核） |
| 人 / 样本 | 单核 RNA：假手术 5、DOCA 5、+finerenone 5、+螺内酯 5、+阿米洛利 2（DOCA、finerenone、螺内酯各有 1 个样本在 3 周，其余在 6 周）；snATAC 2/2/2/2/1；雄性 Sprague-Dawley 大鼠 |
| 标签 | 每个核的治疗组和细胞类型；时间点只在 GEO 样本记录里 |
| 许可 | GEO: not stated |
| 论文 | Abedini A et al. J Clin Invest 2024;134:e157165. doi:10.1172/JCI157165 |

## 测了什么

大鼠肾的单核 RNA 和 ATAC：对照、DOCA 盐、DOCA 盐 + finerenone、DOCA 盐 + 螺内酯，另有阿米洛利组。

## 已知问题

- 是大鼠，不是人；每组 2–5 个样本，每个 DOCA 组在 3 周只有 1 个样本；GEO 的 overall_design 说明已经过时。
