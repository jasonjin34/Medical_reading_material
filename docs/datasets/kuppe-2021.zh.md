# Kuppe 2021 · 人肾纤维化（高血压性 CKD）

> 来自第三个中心（亚琛）的人 CKD 组织，分选成几个部分：用来检验在别的队列上得出的 CKD 假设在这里成不成立，尤其是纤维化。

**物种** 人 · **测法** 单细胞 RNA · **获取** 公开

## 一眼看完

| | |
|---|---|
| 规模 | CD10− 53,672 个细胞，CD10+ 33,690 个，PDGFRβ+ 37,380 个（论文正文；图注里是 51,849 和 31,875） |
| 人 / 样本 | 13 名高血压性肾硬化病人（7 名 eGFR > 60，6 名 < 60）；CD10− 11 人（7 / 4），CD10+ 8 人（5 / 3），PDGFRβ+ 8 个（4 / 4）；没有健康对照 |
| 标签 | 每个细胞的聚类标签（文件里有没有每人的 eGFR 分组还没核对） |

| 论文 | Kuppe C et al. Nature 2021;589:281–286. doi:10.1038/s41586-020-2941-1 |

## 测了什么

人肾里流式分选的 CD10+、CD10− 和 PDGFRβ+ 细胞的单细胞 RNA；空间上用 RNA 原位杂交（RNAscope）核对，没有发布空间数据集。论文把肌成纤维细胞主要追溯到周细胞和成纤维细胞，并在小鼠上用谱系追踪支持。

## 已知问题

- 是分选后的部分，细胞类型比例不等于组织里的比例；没有健康对照，只能比 eGFR 高和低。
- 论文自己的人数前后不一致：正文说两个部分都来自 13 人，按部分又是 11 人（CD10−）和 8 人（CD10+），图 1b 的图注写 15 个肾；Zenodo 文件还没数。
