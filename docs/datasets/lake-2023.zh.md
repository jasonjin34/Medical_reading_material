## 测了什么

单核 RNA（snCv3，203,702 核，36 人）；单细胞 RNA（scCv3，109,741 细胞，45 人，全是活检）；SNARE-seq2 同一个核测 RNA + ATAC（104,809 核，只有 7 名健康人）；空间（Visium，带 H&E 图；Slide-seq）；Visium 切片是伪影注入课题里专家标注的候选（讨论中）。

## 人和样本

论文写 45 名健康参考供体、48 名 AKI / CKD 病人，其中包括只做了空间测序的人。健康组织来自部分或全部肾切除、没有用于移植的死亡供体肾、活体供体活检；论文没有说肾切除是不是因为肿瘤。病人组织大多是 KPMP 研究用穿刺活检，但单核数据里 13 名 CKD 病人中有 3 名来自肾切除（我们数的）。14 个病人同时有单核和单细胞数据（我们数的）。

## 标签

`subclass.l1/l2/l3`（GEO 单核标签表里是 16 个大类、74 个 `subclass.l2` 亚类、77 个 `subclass.l3` 亚类，另有 3,364 个没有标签的核记为 NA；论文说的“77 个亚类”就是第 3 级）和 `state.l1/l2`（reference、degenerative、adaptive、cycling、transitioning）；28 个亚类是 altered。标签是聚类后专家判读的，不是测出来的。

## 已知问题

- 单核数据里，退化态的核基因更少（中位 791 vs 正常 1,736）、线粒体比例更高（3.0% vs 0.6%），像低质量细胞；单细胞数据里正好相反（我们数的）。
- 健康人身上也有 altered 细胞：单核数据里占 26%（作者认为可能来自取样缺血或正常衰老）。
- 原始测序是受控访问（KPMP / dbGaP），拿不到空液滴，没法直接估计 ambient。

## 怎么准备

*2026-10-26 实测，只用 Python（anndata、scanpy、h5py、scipy、pandas、rdata），不需要 R。数据不要放进这个仓库。*

1. 下载 cellxgene 的单核 h5ad（1.57 GB）：172,847 核 × 28,813 基因。`X` 是归一化后的值，整数计数在 `raw.X`。
2. cellxgene 文件里有细胞类型（`subclass.l1/l2`），但**没有 `state.l1/l2`**。再下载 GEO 标签表（19 MB），按细胞 ID 合并：172,847 个全部对得上。
3. cellxgene 版比 GEO 少了 30,855 个核（GEO 共 203,702 个），其中包括**全部 COVID-AKI 病人**（19,678 核）和 3,364 个没有状态标签的核。需要这些的话，改读 GEO 的计数 RDS（第二段代码）。
4. GEO 的 `.RDS` 是 R 的稀疏矩阵（dgCMatrix），用 `rdata` 包在 Python 里就能读，不用装 R（SNARE2 RNA：30,574 基因 × 104,809 核，约 4 秒）。

```python
import scanpy as sc, pandas as pd
adata = sc.read_h5ad("lake2023_sn.h5ad")           # cellxgene single-nucleus file
adata.X = adata.raw.X                               # integer counts
meta = pd.read_csv("GSE183277_Kidney_Healthy-Injury_Cell_Atlas_snCv3_Metadata_03282022.txt.gz",
                   sep="\t", index_col=0, low_memory=False,
                   dtype={"patient": str})          # patient IDs mix numbers and text
adata.obs = adata.obs.join(meta[["state.l1", "state.l2", "condition.l2", "patient"]])

# GEO count matrix without R (gunzip the .RDS.gz first)
import rdata, numpy as np, scipy.sparse as sp
m = rdata.read_rds("GSE183277_Kidney_Healthy-Injury_Cell_Atlas_snCv3_Counts_03282022.RDS")
X = sp.csc_matrix((np.asarray(m.x), np.asarray(m.i), np.asarray(m.p)), shape=tuple(m.Dim))
genes, cells = list(m.Dimnames[0]), list(m.Dimnames[1])   # genes x cells
```
