# 数据集

我们用到的公开肾脏数据，每份一页：测了什么、多少人、有什么标签、在哪下载、什么格式和许可、已知问题，以及被哪个研究课题用到。看不懂测法或术语，先读 **[入门](../onboarding/index.md)**；怎么判断一份数据能不能用，见 [入门 · 怎么读懂一份数据集](../onboarding/07-datasets.md)。

数字都在 2026-10-26 对过 GEO、Zenodo、cellxgene、SRA 和论文原文；标“我们数的”是从下载的标签表里算出来的。

**能不能下载：**2026-10-26 用不下载的方式（每个文件只请求开头 16 字节）检查了 8 个数据集的 33 个文件，全部可以下载、格式正确。每个数据集页面的“怎么准备”一节有实测过的读取步骤和代码。扰动实验那一组是 2026-10-31 加的，只核对了 GEO 记录和论文，还没做下载检查。
