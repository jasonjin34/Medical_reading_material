# ATTEMPT 2026 · SGLT2 抑制剂对安慰剂，基线和 16 周的活检

> 我们找到的唯一一项公开的、有用药前后肾组织单细胞数据的人类随机对照试验：治疗假设在人身上的答案。

**物种** 人 · **测法** 单细胞 RNA · **获取** 公开

## 一眼看完

| | |
|---|---|
| 规模 | 27 份活检，214,415 个细胞 |
| 人 / 样本 | dapagliflozin 组治疗前 9 份、治疗后 7 份；安慰剂组 7 份、4 份（按 GEO 样本记录数的） |
| 标签 | 每个样本的分组和时间点；没有逐个细胞的标签 |
| 许可 | GEO: not stated |
| 论文 | Bjornstad P et al. Sci Transl Med 2026;18:eaee1005. doi:10.1126/scitranslmed.aee1005 |

## 测了什么

用 dapagliflozin 或安慰剂 16 周前后的肾活检单细胞 RNA（试验编号 NCT04333823）。

## 已知问题

- 样本少：随访活检只有 11 份；是青少年的早期病变，效应可能和成形的 CKD 不同。
- 公开文件里没有细胞类型标签，要先注释；这一步本身就是 agent 可能出错的地方。
- GEO 上没有病人编号，公开数据没法把同一个人的基线和随访活检配对，只能按组比较。
