# Gaedcke 2022 · Single cell vs single nucleus after injury

> The same injured kidneys measured two ways, so the size of an assay difference can be set next to the size of an injury effect.

## What was measured

Single-cell and single-nucleus RNA of control, mildly and severely injured mouse kidneys.

## Known issues

- One sample per condition and assay: enough for a size comparison, not for statistics.
