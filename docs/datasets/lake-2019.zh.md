## 测了什么

单核 RNA，用 snDrop-seq（不是 10x）。

## 人和样本

15 人，组织来自肾切除和死亡供体，没有活检。例：病人 3414 的髓质，冷冻 1,401 / Wisconsin 1,533 / RNAlater 3,102 核。

## 标签

簇注释；每个核的处理方式可以从 GEO 样本页的 metadata 恢复（已验证）。原文：酶解离出现应激基因（FOS、FOSB、DNAJB1），一个簇“likely represented a dissociation artifact”，两个簇线粒体偏高，“consistent with … warm ischemia”。

## 已知问题

- 公开矩阵删掉了线粒体基因；处理方式和批次（日期）混在一起；规模小。

## 怎么准备

*2026-10-26 实测，只用 Python（anndata、scanpy、h5py、scipy、pandas、rdata），不需要 R。数据不要放进这个仓库。*

1. 一个 20 MB 的文件：31,522 基因 × 17,659 核，整数 UMI，已删掉线粒体基因。用 pandas 读大约 45 秒。
2. 列名里带着簇号和文库号：`C1_NK5_CCCGCTTCCTCC` = 第 1 簇、文库 NK5。注释表把 30 个簇对应到名称。
3. 每个文库的处理方式（冷冻、Wisconsin、RNAlater、酶解离）在 GEO 样本页上，还需要整理成表。

```python
import pandas as pd
m = pd.read_csv("GSE121862_UCSD-WU_Single_Nuclei_Cluster_Annotated_Raw_UMI_Matrix.tsv.gz",
                sep="\t", index_col=0)                           # genes x nuclei
cluster = m.columns.str.split("_").str[0].str[1:].astype(int)
library = m.columns.str.split("_").str[1]
```
