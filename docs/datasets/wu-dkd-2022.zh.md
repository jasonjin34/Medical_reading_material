# Wu 2022 · 糖尿病肾病小鼠的五种治疗

> 糖尿病肾病小鼠分别接受安慰剂、ACE 抑制剂、罗格列酮、SGLT2 抑制剂和两种联合用药，两个时间点。我们的理解：这是公开数据里最适合做“从单药预测联合用药”的肾脏数据。

**物种** 小鼠 · **测法** 单核 RNA · **获取** 公开

## 一眼看完

| | |
|---|---|
| 规模 | 接近 100 万个核（GEO 摘要） |
| 人 / 样本 | 70 只雌鼠，14 组，每组 4–6 只（每只一个样本） |
| 标签 | 治疗组 × 时间点（2 天、2 周） |
| 许可 | GEO: not stated |
| 论文 | Wu H et al. Cell Metab 2022;34:1064–1078.e6. doi:10.1016/j.cmet.2022.05.010 |

## 测了什么

全肾单核 RNA。分组：安慰剂、ACEi、罗格列酮、SGLT2i、ACEi + 罗格列酮、ACEi + SGLT2i，每组 2 天和 2 周两个时间点；另有 db/m 和不注射肾素 AAV 的 db/db 对照（只有 2 天）。作者报告：不同药物影响的细胞类型差别很大；联合用药效应最大，而且两种药的效应大多不重叠（GEO 摘要）。

## 已知问题

- 是小鼠模型，不是病人；只有五种处理，没法检验“预测任意没见过的扰动”。
