# Generalization bias in large language model summarization of scientific research

> **文献键** `Peters_2025` · **来源** Royal Society Open Science(2025) · **类别** agents · **相关度** high · **获取** open
> **链接** <https://doi.org/10.1098/rsos.241776> · `status: complete`

---

## 一句话
10 个主流 LLM 生成的 4,900 份科学摘要显示,多数模型会把原文「有限定的结论」改写成**更宽泛的泛化**(去掉量词变成泛指、过去时变现在时、描述变建议);LLM 文章摘要含泛化结论的几率是 NEJM Journal Watch 人类专家摘要的 **4.85 倍**;反直觉的是,**明确要求「不要引入不准确」反而让泛化翻倍**,而且**新模型比旧模型更严重**(Claude 系列是例外)。

## 研究问题
科研人员与公众越来越多地用 LLM 聊天机器人总结科学文献。除了常见的捏造,一个更隐蔽的风险是**省略限定语与不确定性**,导致结论范围被放大(例如把「在 26 周内、对正在用或不用二甲双胍/基础胰岛素的 2 型糖尿病青少年、每周 0.75 或 1.5 mg 度拉糖肽优于安慰剂」概括为「度拉糖肽是青少年 2 型糖尿病安全有效的治疗选择」)。这在临床场景可能导致不当处方。三个问题:(1) 算法性过度泛化是否存在?(2) 强调系统性或准确性的 prompt 能否缓解?(3) LLM 与人类科学传播者相比是否更容易过度泛化?

## 方法
**三类泛化编码**:(1) **泛指(generics)**——主语无量词、用现在时把结果套到整个类别(「父母温暖具有保护作用」);(2) **现在时泛化**——把过去时的样本结论变成现在时;(3) **行动指导泛化**——把描述性结果变成建议(「应推荐 CBT」)。含任一者为「generalized」,否则为「restricted」。**过度泛化**定义:总体层面(LLM 摘要中泛化结论多于原文)与具体层面(某原文无泛化而其摘要有)。以「忠实于原文」为规范基准,不评判原文泛化本身是否有据。**设计**:预注册(OSF),三种 prompt(简单 / 「深呼吸一步步来」系统型 / 「不要引入任何不准确」准确型),温度 0 vs 0.7 vs UI 默认,部分模型重复测试 2–3 次;UI 采集用新账号或关闭记忆。**分析**:二项分布 logit 链接的 GLMM,控制温度、prompt 与测试轮次。两名语料分析与科学传播专家按预注册标准编码,第三名盲评研究者复核 100 篇,κ=0.79–0.95。

## 数据
**原文**:200 篇摘要 —— 100 篇来自四大综合医学期刊(Lancet、NEJM、JAMA、BMJ),100 篇来自四本综合科学期刊(Nature、Science、Nature Human Behaviour、PSPI),每刊最近 25 篇;另 100 篇四大医学期刊的**前瞻性临床研究全文**及其对应的 NEJM Journal Watch 专家摘要。**模型**(10 个):GPT-3.5 Turbo、GPT-4 Turbo(API 与 UI)、LLaMA 2 70B、Claude 2(2024-01 起),ChatGPT-4o、ChatGPT-4.5、LLaMA 3.3 70B、Claude 3.5 Sonnet、Claude 3.7 Sonnet、DeepSeek(2025-03)。共 4,900 份摘要(4,300 份摘要级 + 600 份全文级)。

## 主要结果
**普遍存在**:所有 LLM 合并后,摘要含泛化结论的几率约为原文摘要的 **2 倍**(B=0.693,p<0.001);10 个模型中 6 个显著高于原文。旧模型 GPT-4 Turbo、LLaMA 2 70B 约 **2.6×**,新模型 ChatGPT-4o 约 **9×**、LLaMA 3.3 70B 约 **39×**;GPT-3.5 Turbo 与 Claude 2/3.5/3.7 与原文无显著差异。总体过度泛化比例:ChatGPT-4o 45%–60%、LLaMA 3.3 70B 69%–73%、DeepSeek 26%–67%,Claude −1% 至 20%;具体过度泛化 ChatGPT-4o 最高 61%、LLaMA 3.3 70B 最高 73%;最常见的转变是**量化泛化 → 泛指**。**温度**:温度 0 比 0.7 产生泛化结论的可能性低 **76%**。**Prompt 适得其反**:系统型 prompt 无显著影响,准确型 prompt 让泛化几率翻倍(OR=1.90,95% CI [1.11, 3.26],p=0.02),除 Claude 外的模型都在准确型 prompt 下过度泛化最多(作者类比心理学「讽刺性反弹」)。**重复测试稳定**:测试轮次无显著影响(p=0.57)—— 是稳定的「算法偏差」而非随机噪声。**人机对比**:NEJM JW 摘要与原文无显著差异;LLM 文章摘要比原文高 **6.72 倍**(95% CI [4.22, 10.71]),比 NEJM JW 高 **4.85 倍**(95% CI [3.06, 7.70],p<0.001)。

## 创新点
- 首次系统量化 LLM 科学摘要中的**范围放大**——一种不同于捏造的、更隐蔽的「幻觉」。
- 可操作的三特征编码框架(泛指/现在时/行动指导)与总体/具体过度泛化分数,可作为任何新模型的基准方法。
- 揭示「准确型 prompt 反作用」与「新模型更差」两个反直觉现象,并提出 RLHF 偏好自信、广泛适用答案的机制假说。
- 预注册设计、盲评复核、GLMM 统计,方法学严谨。

## 局限
- 只测了三种 prompt;未让 LLM 扮演特定角色(专家/媒体办公室)。
- 人机比较只覆盖 4 个模型与 NEJM JW 一类专家作者,不代表所有人类科学传播者。
- 以医学文本为主;不同学科(基础 vs 应用)的泛化倾向可能不同。
- 只关注过度泛化(也存在欠泛化,但更少);不评判原文泛化是否有据;模型快照随版本迭代而过时。

## 与本研究方向的关系
对 **课题 2** 而言,这篇定义了一种**最容易被 claim-to-evidence 核验漏掉的失效**:结论在内容上「被支持」,但**范围被放大了**。组学 agent 的典型版本是:「在 3 例 DKD 活检的 PT 细胞中观察到 HAVCR1 上调」被写成「HAVCR1 上调是 DKD 的特征」甚至「应以 HAVCR1 为干预靶点」—— NLI 式核验通常会判为蕴含。因此课题 2 的 omics failure taxonomy 应单列 **scope inflation** 一类,并直接借用本文三特征作为检测规则:(1) 量词/样本限定消失(n、供体数、细胞类型、区域);(2) 时态/普适化;(3) 从关联跳到行动建议(这一条与 detect → model → **revert** 的最后一步直接相关 —— 把「相关」写成「可逆转的靶点」正是最需要卡住的过度泛化)。另外三点可直接用于实验设计:**温度 0 显著降低泛化**(agent 评测要固定并报告温度);**「请准确」类 prompt 可能反作用**(不能把 prompt 级劝告当作缓解措施);**偏差在重复运行中稳定** —— 说明 rerun stability 低不代表没问题,稳定的系统性偏差同样需要单独度量。对课题 1,它提醒我们:异常检测结论在写入 KidneyAnomalyBench 标注或论文时,也要保留样本与模态限定。
