# Learning the natural history of human disease with generative transformers

## 一句话
Delphi-2M 把 GPT-2 改造成**连续时间、多病种竞争风险的生成模型**:输入一个人的 ICD-10 首诊序列(1,256 种疾病 + 死亡)及性别/BMI/吸烟/饮酒,同时输出下一事件是什么以及何时发生;在 40 万 UK Biobank 参与者上训练、仅 220 万参数,对 >1,000 种疾病的平均年龄分层 AUC 约 0.76,不改参数迁移到 193 万丹麦人上仍有 0.67,还能采样未来 20 年的合成健康轨迹。

## 研究问题
疾病进展是多病共存、随时间演化的,但现有风险模型多是单病种(心血管、某种癌症),极少有算法能同时预测 ICD-10 顶层 >1,000 种诊断。多病共病建模的难点:诊断种类多、事件间的时间依赖、异质数据整合、预测的统计校准。LLM 把语言建模为 token 序列并逐个生成 —— 疾病史同样是「过去事件 → 预测未来序列」,那么 GPT 式模型能否学会人类疾病的「自然史」,并做到可校准、可生成、可外部验证?

## 方法
基于 nanoGPT 的 GPT-2,三处关键改动:**(1) 连续年龄编码** 替代离散位置编码(sin/cos 基函数,最低频率 1/365,再经可训练线性组合)—— 支持任意长度输入;**(2) 第二个输出头预测到下一事件的时间**,采用**竞争指数等待时间模型**:每个 token 的速率 λᵢ = exp(logitᵢ),下一事件为 j 的概率 = λⱼ/Σλᵢ(恰好等于 softmax 交叉熵),到下一事件的时间服从速率 Σλᵢ 的指数分布,于是 logit 可直接解释为**发病率(每日)**;**(3) 因果注意力额外屏蔽同一时刻记录的 token**。另外:**"no event" 填充 token** 以平均每 5 年 1 个的速率随机插入,消除长时间无记录的空窗(也让推理时可在任意时刻查询风险);性别、BMI(<22/22–28/>28)、吸烟、饮酒作为输入 token 但不进损失;生活方式 token 的时间在入组点 −20 到 +40 年间随机化以打破 immortal-time 偏倚造成的虚假关联。超参扫描复现 scaling law,UK Biobank 规模下最优约 200 万参数;选用 120 维、12 层、12 头、**220 万参数**。权重绑定(输入嵌入 = 输出投影)便于解释。训练:Adam,20 万迭代,batch 128,cosine 学习率 6e-4→6e-5。**采样**:从 softmax 采下一疾病,从各指数分布采时间取最小,迭代得到完整轨迹。**可解释性**:嵌入 UMAP、SHAP、注意力图。

## 数据
**UK Biobank**:约 50 万人(2006–2010 年入组,37–73 岁);疾病来自 "first occurrence"(类别 1712,整合初级保健、住院、死亡登记、自报)+ 癌症登记(自行补入),ICD-10 level-3,共 1,256 种诊断。训练 402,799 人(80%),验证 100,639 人(20%),纵向测试 471,057 名 2020-07-01 仍在世者(2021-07 至 2022-07 的发病,留 1 年空窗)。**丹麦外部验证**:国家患者登记(LPR)+ 死因登记,2016-01-01 时 50–80 岁的 **193 万人**,1978–2016 年 1,151 万个疾病 token,在 2017 年发病上评估(796 种 ICD-10 码,每种 ≥25 例);ICD-8 映射到 ICD-10,无生活方式数据(视为缺失)。

## 主要结果
- **全病谱预测**:内部验证下一事件平均年龄分层 AUC **≈0.76**;97% 的诊断 AUC > 0.5;死亡 AUC **0.97**;5 年年龄段校准良好。
- **远期预测**:10 年后平均 AUC 从 0.76 降到 **0.70**,仍有远期预后价值。
- **对比专用评分**:心血管病与痴呆接近常规临床评分(QRisk3、SCORE2、PREVENT、Framingham、UKBDRS),死亡优于 Charlson/Elixhauser;**糖尿病不如单一 HbA1c**;多数病种 AUC 高于基于 67 个血液标志物的 MILTON(可比 410 种病)。
- **生成轨迹**:以 60 岁前病史为条件采样 63,662 条轨迹,70–75 岁时的人群发病率被很好重现;第 1 年约 17% 疾病 token 预测正确,20 年后 <14%(仅用年龄性别为 12–13%)。
- **纯合成数据训练**:只在合成轨迹上训练的模型在真实验证集上 AUC **0.74**,仅比原模型低 3 个百分点 —— 合成数据可作为隐私更低敏感的替代。
- **外部验证**:不改参数用于丹麦,平均 AUC **0.67**(s.d. 0.09)vs UKB 纵向测试 0.69;两数据集各病种性能相关 r = 0.76(95% CI 0.72–0.80)。
- **可解释性**:嵌入按 ICD 章节自发聚类(模型不知道章节);两型糖尿病与视网膜病、神经病变聚在一起;心梗、败血症与死亡聚在一起。SHAP 示例:一系列消化系统诊断使某人胰腺癌风险升高 19 倍。癌症对死亡率的影响半衰期数年,败血症则迅速回落。
- **偏倚**:模型学到了数据采集过程 —— 仅在住院记录出现的疾病,在已有其他住院记录者中预测速率平均高 10 倍(败血症 93% 在医院确诊,预测速率高 8 倍);UKB 的健康志愿者偏倚、入组前无死亡(immortality bias)、80 岁以上数据稀少都被模型继承。

## 创新点
- **竞争指数等待时间头**:让 GPT 的 softmax 同时成为疾病发生率模型,输出可解释的绝对速率而非仅相对概率。
- 连续年龄编码 + 同时刻屏蔽 + no-event 填充:把「文本 GPT」改造为「连续时间事件 GPT」的一组小而必要的改动(有消融)。
- 单模型同时覆盖 >1,000 种疾病,并在另一国家数据上**零调参外部验证**。
- **生成式**:采样 20 年未来轨迹做人群疾病负担预测;用合成数据训练下游模型。
- 坦率的偏倚分析:展示模型如何「学到」数据来源缺失模式。

## 局限
- 只有首次诊断 + 少量生活方式;无化验、用药、影像、文本(作者列为扩展方向;糖尿病上明显不如 HbA1c)。
- UKB 偏倚:健康志愿者、白人比例高、较富裕;入组前无死亡;80 岁以上数据不足。
- 模型利用了数据来源缺失模式(住院记录有无),部分关联是数据采集的伪迹。
- 作者明确告诫:时间方向上的依赖**不可作为因果**来干预未来健康。
- 个体层面预测受随机性主导,与一系列结局都兼容;临床决策支持还需监管框架。

## 与本研究方向的关系
**对 Sinai EHR 项目,这是「病人轨迹基础模型」的最清晰范式**:一个小模型(220 万参数)在 40 万人上就能学到 >1,000 种疾病的竞争风险,而 Sinai 有数百万病人 —— 按本文复现的 scaling law,Sinai 规模下最优模型应明显更大,这本身就是一个可检验的问题。可直接借鉴的设计:(1) **竞争指数头**给出可校准的绝对发生率,适合把 CKD 分期进展、透析、心衰、心梗、死亡作为**相互竞争**的终点同时建模 —— 正是心-代谢-肾(cardiometabolic-kidney)共病的本质;(2) no-event 填充让模型可以在任意时刻查询风险,适合做「风险随时间的轨迹」;(3) 外部验证规范(零调参迁移 + 各病种性能相关性)。**明确的空白也正是 Sinai 的机会**:Delphi 在糖尿病上输给 HbA1c,说明对代谢-肾病终点,**化验值(HbA1c、eGFR、UACR)和用药(SGLT2i、GLP-1RA、RAS 抑制剂)是必须加入的 token** —— Sinai EHR 恰好有这些而 UKB first-occurrence 数据没有。对实验室 Novo 资助的心-代谢-肾智能体:一个 Delphi 式模型可以作为 agent 调用的**数值预测工具**(作者在讨论中也提出 LLM 调用 Delphi 来提升数值准确性),这与 Plan B 的「agent 结论必须挂在可验证的计算证据上」一致。**偏倚部分对 Plan A 的思路是同构的**:模型学会了「数据来源缺失模式」而非疾病 —— 这与组学里把批次/伪迹当成疾病信号是同一类问题;Plan A 用跨模态一致性区分伪迹与疾病,EHR 上的对应做法是对数据来源/就诊强度做显式建模或分层检验。与 detect → model → revert:Delphi 是病人尺度的「model」(可生成、可采样的虚拟病人),但作者明确说不可做因果干预 —— 要走到 revert,需要因果/反事实层或与组织层 virtual tissue 的连接。
