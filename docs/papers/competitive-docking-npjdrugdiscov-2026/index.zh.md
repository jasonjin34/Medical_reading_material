# AI-guided competitive docking for virtual screening and compound efficacy prediction

> **文献键** `Mirgaux_2026` · **来源** npj Drug Discovery(2026) · **类别** drug-discovery · **相关度** medium · **获取** open
> **链接** <https://doi.org/10.1038/s44386-026-00039-4> · `status: complete`

---

## 一句话
作者发现 AF3 / Boltz-1/2 这类扩散式 co-folding 模型**对任何分子都会生成一个看似合理的结合位姿**,于是提出两个很朴素但有效的判据:**(a) 位姿收敛性**——同一配体在多个随机种子下预测位姿彼此的平均 RMSD,真抑制剂通常 < 2 Å 且落在结合口袋 5 Å 内,无关分子则发散且远离;**(b) 两两竞争对接(pairwise competitive docking)**——一次把两个配体一起放进去共折叠,谁占住活性位点谁赢,胜率即 **CDS(Competitive Docking Score)**,据此排出抑制剂顺序。在 17 个蛋白系统(19 个结合位点)上,CDS 排序与实验活性的一致性指数 c 从 0.52(无相关)到 0.89(强相关),与 Boltz-2 自带的亲和力预测模块总体相当;把这招推广成 "All-at-Once"(一次放 25–26 个分子竞争)后,在 3,155 个 FDA 已批准药物的库里找氟喹诺酮,叠加位姿过滤后富集度达 93.5%、富集因子 62。

## 研究问题
扩散式生成模型(RoseTTAFold All-Atom、AlphaFold3、Boltz-1/2 等)在预测蛋白-配体复合物结构上已经很准,往往超过传统对接程序,但有一个根本缺陷:**它们对真 binder 和无活性分子都会给出一个结合位姿**。虽然很多模型附带打分指标,但准确推断结合亲和力仍然困难。论文把问题收成两问:(i) 如何把真实结合与假阳性区分开?(ii) 如何让预测位姿的排序反映预期的结合亲和力?这两问就是全文的动机。

## 方法
**(1) 位姿判据**:对每个配体用**至少 5 个随机种子**做模型推理,每次推理生成**至少 25 个模型**;把预测的蛋白叠合到参考晶体结构上(PyMOL 的 super 命令),然后看两件事——配体距参考结合位点中心的距离、以及多个预测位姿彼此的平均 RMSD(即位姿收敛性)。真抑制剂的经验阈值是距离 < 5.0 Å、收敛性 < 2.0 Å。**(2) 两两竞争对接**:把蛋白模型与**两个相互竞争的配体**一起交给 co-folding 模型推理,占住活性位点的那个算这一轮的赢家;对每一对配体做至少 n 次独立推理,胜率(百分比)即 CDS;把所有配体两两对战的结果汇成一个**配对矩阵**,按累计 CDS 排序。**(3) All-at-Once(为降低成本的简化版)**:不做两两对战,而是把整类抑制剂一次性放进一次推理里竞争。用于虚拟筛选时,把 3,155 个化合物的库随机切成 **124 组**(109 组各 25 个、15 组各 26 个——分组大小由 GPU 显存决定),每组做一次 All-at-Once 推理。**(4) 多位点系统的处理**:在有多个口袋的系统里,可以**先用已知配体把其他位点占住**,再让目标配体竞争——论文在 DNA gyrase 上就是这么把别构抑制剂逼回正确位点的(加入 gepotidacin 封 NC 位点、sparfloxacin 封 FQ 位点)。**(5) de novo 设计**:用 **STONED 算法**在前 5 名 FQ 周围的化学空间自动生成数千个分子,选出 414 个,逐个与排名最高的 FQ(STF)做竞争对接。**(6) 模型与算力**:AF3 源码 2024-11-14 从 GitHub 取得、参数直接向 Google 申请;Boltz-1/2 从官方 GitHub 本地安装,也测了施加物理势的 steering 版本;推理用 NVIDIA RTX 4080(16 GB)、RTX 3090(24 GB)或 A40(48 GB),序列与模板检索用 11 代 Intel 8 核 CPU + 128 GB 内存;为省时间,每个系统的多序列比对预先生成,DNA、离子、化合物等非蛋白组分在推理前就并入。结构相似度用 RDKit 的 ECFP4 指纹算 Tanimoto 系数,位姿合理性用 PoseBusters 检验,统计上用 c-index(秩一致性)、Pearson r 与 Spearman 检验。

## 数据
**基准蛋白**:16 个功能各异的靶点,外加结构更复杂的多位点系统 Mycobacterium tuberculosis(Mtb)DNA gyrase,合计 17 个系统、19 个结合位点。文中点名的靶点包括激酶 CDK2 与 TYK2、蛋白酶 thrombin、水解酶 PDE2 与 BACE1、驱动蛋白 KIF11/EG5、磷酸酶 PTN11 与 PTP1B、氧化还原酶 DHFR 与 COX-1/COX-2、BCL-2 样蛋白 MCL1、GPCR HCAR3 与 FFA2R、凝集素 GAL3、PAS 结构域 EPAS1,以及后来追加的两个近期才解出配体结合态 cryo-EM 结构的 GPCR 系统 GPER1 与 SLC6A3。**对照分子**:每个基准靶点配 **28 个无关的"off-target"化合物**——由其他靶点各取一个抑制剂、再加上一些结合完全无关蛋白的化合物组成。**DNA gyrase 的三个位点**:FQ 位点(氟喹诺酮)、NC 位点(non-catalytic,NBTI 结合,距 FQ 位点约 10 Å,位于两个 DNA 断裂键之间)、别构位点(噻吩类抑制剂,距 FQ 位点约 30 Å)。**排序评测用的实验数据**:来自文献与 Binding Database;另外作者**自己测了** 22 个 FQ 抑制大肠杆菌生长的 IC50。**筛选库**:3,155 个 FDA 已批准分子,其中 46 个是 FQ(占 1.5%)。**抗性变体**:4 个已知使 IC50 或 MIC 升高数倍的 DNA gyrase FQ 抗性变体。

## 主要结果
- **位姿收敛性能分真假 binder**:在 16 个基准上,真抑制剂一般结合在口袋约 5 Å 内且收敛性通常 < 2 Å,off-target 分子位置更远、变化更大。**位姿收敛这个判据总体上优于 Boltz-2 的 binding-likelihood 预测**。特异性最强的是 CDK2、TYK2、EPAS1、PDE2、PTP1B、PTN11、DHFR、GAL3、MCL1;最弱的是 GPCR FFA2R 与 HCAR3、水解酶 BACE1,其次是 COX-1——这些系统里一些 off-target 分子仍然落在口袋附近且 RMSD 很低。
- **多位点系统(DNA gyrase)**:FQ 平均落在已知位点 2 Å 以内;非 FQ 的 spiropyrimidinetrione 类(QPT-1、zoliflodacin)也一样,因为它们本来就作用在 FQ 位点;NBTI 稳定落在其位点 2 Å 内,**AF3 与 Boltz-1 都做到了,Boltz-2 没有**。但噻吩类**别构**抑制剂在三种模型下都很少被对接到正确位点,多数被错放到 FQ 或 NC 位点——**除非先用已知配体把那两个位点占住**,这时它们就守在正确位点。论文还指出这一现象在另一个 20 对正位/别构配体、17 个蛋白的独立数据集上也被报道过。
- **CDS 排序与实验活性的一致性(AF3)**:强相关的有 GAL3(c = 0.89)、TYK2(0.87)、thrombin(0.86)、CDK2(0.78)、HCAR3(0.77)、KIF11(0.76)、DNA gyrase 别构位点(0.76)、PTN11(0.75)、PTP1B(0.74)、DNA gyrase FQ 位点(0.72);中等的有 FFA2R(0.66)、EPAS1(0.67)、MCL1(0.68)、PDE2(0.67)、DHFR(0.68)、DNA gyrase NC 位点(0.62)、BACE1(0.62)、COX-2(0.67);**COX-1 只有 0.52,等于没有相关性**。注意这两个最差的系统(COX-1/COX-2)本来位姿收敛性就差,说明问题出在"配体根本没被可靠地放进正确口袋",而不是竞争机制本身。用 Boltz-1/2 替代 AF3 做竞争对接,相关性普遍更弱,COX-1、COX-2、PDE2、PTP1B、TYK2 上**没有显著相关**。
- **与 Boltz-2 亲和力预测模块的对比**:在 19 个系统上两者总体相当,只有细微差别——Boltz-2 在 BACE1、DHFR、EPAS1、FFA2R、PTP1B、PDE2 上略好,竞争对接在 DNA gyrase 别构位点、CDK2、GAL3、HCAR3、PTN11、TYK2、COX-2 上略好。**在两者都表现差的系统(DNA gyrase NC 位点、COX-1、COX-2)上,竞争对接仍然更好**——这是它作为"直接亲和力预测器失效时的替代方案"的价值所在。
- **分不开高度同源的口袋**:COX-1 与 COX-2 抑制剂的 CDS 排序几乎相同(Pearson r = 0.96),说明 AF3 无法可靠区分这两个环氧化酶同工酶,原因很可能是它们结合位点高度保守。同理,4 个 FQ 抗性变体的位姿特异性与 FQ 排序相对野生型**只有微小变化**——"换一两个催化位点的氨基酸不足以显著改变 AF3 的结合预测",这与另一项关于 co-folding 方法无法响应刻意扰动的研究一致。大肠杆菌里换用第二靶点拓扑异构酶 IV 也无法细化排序,与用 DNA gyrase 得到的排序几乎相同(r = 0.99)。
- **自测实验数据的验证**:22 个 FQ 抑制大肠杆菌生长的 IC50 与 CDS 排序整体相关性一般,但趋势清楚——IC50 低的 FQ 普遍 CDS 排名高;剔除两个预测水溶性差的 FQ 后相关性显著改善(FQ 本来就以水溶性差著称)。
- **All-at-Once 用于虚拟筛选**:在 3,155 个 FDA 药物(含 46 个 FQ,占 1.5%)的库上,挑出 **147 个**排名最高的化合物,其中 **38 个是 FQ**,即 **25.9% 富集**;没被选中的 8 个 FQ 已知对 Mtb DNA gyrase 抑制活性低,且多属第一代 FQ。再叠加位姿过滤(收敛性 2.5 Å、距结合位点 2.0 Å)后,剩余 45 个化合物中 FQ 富集到 **77.8%**;把阈值收紧到 1.0 Å 进一步提高到 **93.5%,富集因子 62**。与 Boltz-2 在同一库上的 hit 识别表现接近。计算上的意义是:3,115 个化合物不必逐个做非竞争对接,只有 All-at-Once 选出的 147 个需要进一步分析。
- **All-at-Once 不如两两对战精细**:整类抑制剂一次竞争时结果较粗——一些强效抑制剂没出现在领先者里,真正占住口袋的化合物数量太少,不足以做可靠的比较分析。它擅长的是"把强 FQ 从弱 FQ 和非 FQ 里挑出来",不适合做精细排序。
- **de novo 设计(概念验证)**:414 个 STONED 生成的分子中,**31 个**在 100 个生成模型里有至少 70% 占住 FQ 位点,即预测结合能力强于当前最佳的 STF;它们与 STF 的 Tanimoto 相似度在 0.25–0.88 之间。由于这些分子都不在 CAS 数据库里(即很可能从未被合成),作者又按预测 ADME 性质过滤,最终只有 **8 个**同时具备良好类药性、溶解度与合成可及性。这些分子尚未合成或实验验证。

## 创新点
- 用"**多种子下的位姿收敛性**"作为区分真假 binder 的判据,比模型自带的 binding-likelihood 更可靠——一个几乎零成本、只需多跑几个种子就能得到的信号。
- 把"**让两个配体在同一个位点竞争**"变成排序方法:作者认为用机器学习工具模拟配体间的虚拟竞争是新策略(以往的竞争对接多用于在大口袋里并排放多个配体,或用于基于片段的设计)。它的可解释性很好——赢家就是占住位点的那个,不依赖外部打分函数。
- **封位点的技巧**:在多位点系统里先用已知配体占住其他口袋,能把别构抑制剂逼回正确位点——这是一个可直接复用的实用操作。
- All-at-Once 给出了"**两步筛选**"的成本结构:先用一次多分子竞争把 3,155 个压到 147 个,再只对这 147 个做位姿精算,最终富集 93.5%。
- 诚实地把方法的**系统依赖性**作为结论的一部分报告出来(c 从 0.52 到 0.89),而不是只报平均值。

## 局限
- **不普适,必须逐案评估**。作者自己把这条写成结论:方法表现强烈依赖具体蛋白系统、抑制剂类别、分子大小与复杂度。根本原因是 co-folding 模型的蛋白-配体预测**严重受训练数据中位姿记忆的影响**,对训练集里没有出现过的配体或结合环境预期表现很差;作者用两个近期才解出配体结合结构的 GPCR 系统(GPER1、SLC6A3)做了直接检验,结果相关性都弱,反倒是 Boltz-2 的 IC50 预测更好(c 约 0.6–0.7)。
- **大分子会崩**。深度学习 co-folding 模型容易产生非物理的瑕疵(原子碰撞、键被拉长、手性违背),所以方法在大或复杂的配体上往往失败:HIV-2 蛋白酶(HIV2P)与 tankyrase 2(TNKS2)两个系统就因为竞争抑制剂太大、碰撞过多而**无法可靠评测**。
- **配体-配体相互作用是一个干扰项**:在能同时容纳两个竞争分子的大口袋里,或在像 DNA gyrase 这样的多位点系统里,胜负可能由配体之间的相互作用而非配体-蛋白相互作用决定。文中一个具体例子:两个 FQ 一起对接时只有一个占住催化 FQ 位点,另一个常常贴在第二个催化位点的 DNA 上(而那个位点在所用模型里只被部分表示)。
- **成本随配体数平方增长**:构建完整的两两竞争矩阵是 O(n²) 次推理,这直接限制了可排序的配体数量;All-at-Once 虽便宜但明显更粗糙,而且分组大小被 GPU 显存卡住(25–26 个)。
- **分不开高度保守的同源口袋**(COX-1 vs COX-2,r = 0.96),也**感知不到抗性突变**(改 1–2 个催化位点残基几乎不改变预测)——这两点对"按靶点选择性做药"和"预测抗性"这两类实际需求都是硬伤。
- **de novo 设计那部分只是概念验证**:8 个候选分子都未合成、未做实验验证,作者明确说这有待后续研究。AF3 的使用还依赖向 Google 申请模型参数,复现性上有外部依赖。
- **与 Boltz-2 的对比样本太小**:作者自己说"更稳健的比较需要在更多系统上做"。Steering 版 Boltz 虽然消除了原子碰撞,但竞争对接表现并没有显著改善;RoseTTAFold All-Atom、Chai、Protenix、NeuralPlexer 等其他模型都还没评测。

## 与本研究方向的关系
这是 Sikander 给 **"Autonomous scientific orchestration of virtual screening"**(Hayat Lab 的硕士/HiWi 课题:LLM agent + 分子基础模型 + docking + active learning,给定蛋白结构自主规划、执行、改进筛选,应用方向心脏疾病)指定的四篇阅读材料之一,在 pipeline 里的位置是**最末端的精排与判真层**:`drugclip-science-2026` 从几亿分子里秒级取候选 → `adaptiveflow-natbiotech-2026` 的 ATG-VS 做大规模对接 → 本文的 AF3 竞争对接给最后几十个候选排序并剔除假阳性。**(1) 对 agent 最有用的两件东西**:**位姿收敛性**是一个几乎免费的"**自我一致性检验**"——多跑几个种子、看预测彼此是否一致,这正是 agent 判断"这个工具的这次输出该不该信"所缺的信号,而且它在论文里**优于模型自带的 binding-likelihood**;**CDS 的胜率**天然是一个有界、可解释、可累积的量,比裸的打分值更适合做 agent 的决策依据。**(2) agent 要做的决策**:什么时候从便宜的检索/对接升级到昂贵的 co-folding(论文的两步法已经给出成本结构:3,155 → 147 → 位姿精算);排序用两两对战(贵、精细)还是 All-at-Once(便宜、粗);多位点系统里要不要先封位点、用哪个已知配体去封;位姿过滤的阈值取多紧(论文给了 2.5 Å/2.0 Å 与 1.0 Å 两档,富集从 77.8% 到 93.5%,但剩下的化合物数会变少——典型的精度/召回权衡,正是 agent 该算的账)。**(3) 一个合理的第一个里程碑**:**先把这一层做成"验真器"而不是排序器**。用论文公开的 Zenodo 数据和 3,155 个 FDA 库复现 All-at-Once 的两步筛选,把"多种子位姿收敛性"包成一个独立工具,然后在前面任意一层(DrugCLIP 的 top-k 或 ATG-VS 的 top hits)后面接上它,量化它剔除了多少假阳性。评测指标直接用富集因子,ground truth 是已知的 FQ 标注,**完全不需要湿实验**。**(4) 这篇对"agent 可信度"这条线的意义最大**:论文给出的是一个**外部的、与模型自身打分无关的**可靠性判据(位姿收敛 + 竞争胜率),而且明确展示了模型自评(Boltz-2 binding likelihood)不如这个外部判据——这与我们在 agent 方向上主张"要用外部 verifier 取代模型自评"是同一个论点,只是落在分子层面。**(5) 必须当心的坑**:(a) **记忆而非物理**——co-folding 的表现靠训练集里的相似位姿,所以 agent 在新颖骨架或新口袋上会系统性高估自己,这里**没有**校准过的不确定性可用,GPER1/SLC6A3 的失败就是警示;(b) **分不开同源口袋**意味着这一层**不能用来做选择性判断**(心脏靶点里同家族成员很多,这一点很要紧);(c) **抗性突变不敏感**,别指望用它预测耐药;(d) O(n²) 的成本必须由 agent 显式预算,不能让它自由地两两对战;(e) 大配体会因碰撞直接失效,agent 需要一个前置的分子大小/复杂度检查来决定这条路走不走。
