§1核心问题树 (问题演进版 · 每条线:问题 → 早期 → 局限 → 最新 2025 → 未解)

一条主线,三道坎的演进

「学正常 · 标偏差」如何在三道坎上一步步演进

读法:每条线从早期答法 → 暴露局限 → 走到 最新(2025),末端接现实核查与落地避坑。

地基 · 为什么 & 范式

异常开放、标不全 → 学正常、标偏差

监督枚举疾病不可扩展 → learn-normal, flag-deviation(全场地基)。 [18][19]
开场钩子:范式很优雅,却几乎没进临床 —— 真正落地的都是监督式窄工具(糖网筛查、卒中/急诊分诊);本讲的无监督 AD 还停在 benchmark、临床可用性有限 [33]。三张力 = 跨不过去的原因(② 最硬)。
① 怎么表示「正常」

两条路,各自向更强先验/特征演进

重建 vs 嵌入 —— 见下两支。
重建派

学健康生成器 → 画不出病灶 → 残差=异常

AE/GAN(2017–19) → 局限 identity shortcut · 模糊 → diffusion(AutoDDPM'23 · THOR'24)→ 最新 Synomaly 多阶段扩散(MedIA'25) [30]
子家族(差在怎么"卡住"正常先验)—— AE 谱系:AE(空间瓶颈)·VAE(概率隐)·VQ-VAE(离散码本)·MemAE(正常原型记忆)·去噪/上下文 AE(掩码重绘) · GAN:AnoGAN(latent 搜索,慢)→ f-AnoGAN(加 encoder 快) · 扩散:DDPM → AnoDDPM(Simplex 噪声控病灶大小)→ AutoDDPM(mask-stitch-resample)→ latent diffusion → Synomaly
嵌入派

特征 + memory bank(不重建)

PatchCore'22(工业·非医学) → 最新 DINOv2 基础模型特征:AnomalyDINO'24 [27] · 医学 DINO-DPMM(MICCAI'25) [28]
② 特异性门槛 · The specificity bar

低患病率下,假阳淹没医生 —— 全体方法的临床坎

平衡集 AUROC 0.95,到 1% 患病率下几个%假阳 × 海量正常 → 虚警淹没医生 → alert fatigue → 弃用;「检测一切异常」也难过监管。specificity 是全体方法的临床坎 —— 见下两支怎么应对。
重建派机制:噪声悖论

擦病灶 ↔ 毁解剖,两头不讨好

噪声太小→病灶残留→漏检(敏感↓);太大→毁健康解剖→假阳(特异↓) → 早期靠调噪声(AnoDDPM Simplex 控尺度)→ 局限 调噪声两全不了 → 最新 改靠引导:THOR'24 隐式引导 → cDDPM 原图作条件重建(2025) [7][31]
feature / VLM:无此悖论

不重建就没有噪声悖论,但特异性仍开放

嵌入/VLM 不擦不画 → 无悖论,却换来另一套坎:距离分数怎么定临床工作点、跨中心阈值漂移 → specificity 整体仍未解
③ 稀缺 & 泛化

几乎无异常数据(稀缺)+ 一个模型要跨很多模态(泛化)

两条路,但不对称:自造异常 → 只解决「稀缺」;借基础模型(VLM)→ 稀缺 + 跨模态都答。「跨模态」这半几乎全靠 VLM —— 见下两支。
自造异常(self-sup)

合成缺陷 → proxy 分割

CutPaste 剪贴块 / FPI 异物插值 / PII Poisson 融合(2020–21) → 造出「哪里不对」当 proxy 分割 → 局限 synthetic ≠ real(学到拼贴痕迹、不迁移)→ 最新 ART-ASyn:解剖合理位置 + 真实纹理合成(CXR,2025) [32]
⤷ 只答「稀缺」:通常单模态各造各的,不解决跨模态泛化。
借基础模型(VLM)

适配 CLIP,少/零样本

zero-shot CLIP 在医学崩(域 gap)→ MediCLIP 可学 prompt / MVFA 多级 adapter + 像素级 V–L 对齐(2024) → 最新 MadCLIP:跨数据集实测 > MVFA(MICCAI'25) [29]
⤷ 注:VLM 也是一种「表示正常」(①),本讲归 ③ 因它主解稀缺/跨模态;「泛化」这条线也横跨 ① —— DINOv2 嵌入(AnomalyDINO / DINO-DPMM)同样是跨模态的一招。
现实核查

别一味追 diffusion / 新 SOTA —— 先质疑评测,再质疑模型 据 MedIAnomaly [15](5 模态 / 7 数据集 / 30 方法统一评测)

两层现实:模型没有通吃赢家 · 领先多来自评测口径 —— 见下两支。
现实 A · 模型:没有通吃赢家

调好的 AE 就 competitive,扩散并不稳定领先

朴素 AE 是很强的基线 · 扩散随模态大幅波动、并不稳定胜出 · 残差度量影响很大(感知/SSIM 常 > L1/L2,依数据集)· 排名随数据集翻转 [15]
⤷ 选型不看榜:模态 · 数据规模 · 可解释性/算力约束 共同决定用重建还是特征/VLM;具体 AUC 依数据集,引用前须再核原文表格。
现实 B · 评测:病灶在评测,不在模型

「缺乏公平、全面的评测,导致结论含糊、阻碍发展」

常见数据集上一个朴素 AE 就近乎满分 → 说明数据集本身不合适,旧「SOTA」的领先多来自评测口径/数据集不当而非真实进步 [15]
⤷ 启示:别被榜单带节奏 —— 把力气从「刷 benchmark」转到 ②特异性 / ③泛化 这些还没解决的真问题。
落地避坑

想落地 AD,先绕开这三个坑:可解释 · 3D · 可信 都不是「原始精度」的问题 [33]

每个坑都有具体证据、不是愿景 —— 见下三支,各自「坑 → 怎么避」。
落地坑 ① · 可解释

别把热图当解释 —— 对 AD 尤其难

坑:异常热图只是间接证据、不是诊断(无病名、分数未校准、saliency 可能不忠实),AD 分数相对/阈值依赖、难与病理语义对齐 [33][19]
⤷ 怎么避:别 oversell —— 热图只当线索;真要做可解释,得测 faithfulness、把分数校准成有临床意义的置信度,而不是配一段「看着合理」的说辞 [33]
落地坑 ② · 3D / 体数据

别把 2D 逐层套 3D 就当「做了 3D」

坑:逐层 2D 丢体积上下文(正常分布更难学),3D 生成算力是主瓶颈 [26];3D UAD 已被单列为独立研究方向(专门 survey & benchmark) [34]
⤷ 怎么避:要么老实说清 2D 的代价,要么走隐空间降算力 —— latent 重建已被证实可提速约 10×、让 3D 上下文变可行 [26]
落地坑 ③ · 可信

别只报 AUROC 就说「能用了」

坑:平衡集上的高 AUROC ≠ 可用 —— 低患病率假阳 · 跨中心域漂移(设备/协议/人群)· 数据/像素级标注稀缺 · 隐私与治理/可问责 都是硬门槛 [33]
⤷ 怎么避:先问三件事 —— 低患病率下假阳多少?换一台机器/一个中心还成立吗?隐私与部署后监测谁负责?这些要在建方法时就想,不是发完论文再补 [33]
⚠️ 诚实提醒:标准 survey 把医学 AD 分成 4 类方法(重建 / 特征嵌入 / 自监督 / 基础模型)[15][33]。本讲把它们重组为三张力:① = 重建 + 嵌入,③ = 自监督 + 基础模型,并把 survey「挑战」里的 specificity 提为一条主轴(②)。方法与挑战都出自 survey、可引;唯「三张力」这个组织方式是本讲的。
