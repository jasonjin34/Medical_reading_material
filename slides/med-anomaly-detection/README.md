# Slides — 医学领域异常检测与基础模型控制

A self-contained HTML slide deck (19 slides, ~30 min) on **anomaly detection in
the medical domain** and its comparison with foundation-model control
(LogicAD · EcoDiff · Minimalist Erasure · UniForget).

## Open it
Just double-click `index.html` (no build, no internet needed).

## Controls
- **→ / Space / PageDown** — next step (reveals one bullet at a time)
- **← / PageUp** — back
- **N** — toggle speaker notes (讲者提示) at the bottom
- **F** — fullscreen · **Home/End** — first/last slide

## Edit
Everything is in `index.html` (inline CSS + JS). Each slide is a
`<section class="slide" data-notes="讲者提示…">`; step-by-step points use
`class="fragment"`; `data-notes` holds the presenter hint shown by **N**.

## Print to PDF
Open in Chrome → the deck is one slide at a time on screen; for a PDF handout use
the browser's "Print → Save as PDF" after pressing **F** / or ask to add a
print-stylesheet that lays out all slides.
