# Foundation models / 基础模型

> A large model pretrained on broad, mostly unlabeled data that can be adapted to many downstream tasks with little extra labeling.
> 在大规模、大多无标注的数据上预训练的大型模型,只需少量额外标注即可适配多种下游任务。
