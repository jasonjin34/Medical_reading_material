## 一句话 / One-liner
<!-- ZH --> scBench-Long(LatchBio)把 scBench 从"单步"推进到"长程":21 个评测、5 个研究系统,要求 agent 从原始或接近原始的单细胞数据出发、不给方法地**恢复一个具体的科学结论**,结论用受控词表确定性判分,另配轨迹 rubric 做诊断;1,068 条轨迹中最强的模型-harness 组合(Claude Opus 4.8 + Claude Code)也只通过 16/63(25.4%),且失败主要不是工具使用失败,而是**科学推理失败**。
<!-- EN --> scBench-Long (LatchBio) moves scBench from single steps to long horizons: 21 evaluations across 5 study systems in which agents start from raw or near-raw single-cell data, with no prescribed method, and must **recover a specific scientific conclusion**, graded deterministically over controlled vocabularies with companion trajectory rubrics for diagnosis. Across 1,068 trajectories the best model–harness pair (Claude Opus 4.8 + Claude Code) passes only 16/63 (25.4%), and failures are mostly **scientific-reasoning failures**, not tool-use failures.

## 研究问题 / Problem
<!-- ZH --> 单细胞研究的结论需要经过多步流程、整合元数据、实验设计、辅助证据(TCR、染色质、验证实验)才能得出;已有基准要么考广义知识,要么考可执行流程或局部步骤。长程任务的难点是**可验证的 ground truth 难定义**:同一数据可支持多种合理结论,已发表结果也未必能独立复现。问题是:如何既约束可接受答案的集合,又不惩罚合理但未预料到的分析路径?
<!-- EN --> Single-cell claims emerge from multi-step workflows that integrate metadata, design and auxiliary evidence (TCR, chromatin, validation experiments); existing benchmarks test broad knowledge, executable workflows or local steps. The long-horizon difficulty is that **verifiable ground truth is hard to define**: the same data support multiple valid claims and published results do not always reproduce. How to constrain admissible answers without penalising valid, unanticipated analysis paths?

## 方法 / Method
<!-- ZH --> **以研究系统而非独立数据集组织**:每个系统贡献多道题,从不同角度(细胞身份、状态、调控、组成、机制)反复审问同一实验。**论文声明只作为候选题来源,不自动当作真值**:只有当目标结论能从提供给 agent 的数据中被独立复现、并经审阅、干扰项设计和多模型轨迹检查后才保留。每题打包:精简的科学问题、原始/近原始数据节点、所需辅助资源、受控答案面、复现笔记、轨迹 rubric。**答案面**围绕分析者真正推理的对象:细胞态身份、供体组成、调控因子与方向、克隆型/库声明、配体-受体解释,以及**"机制需谨慎"标签**;干扰项专门用来区分数据支持的结论与常见捷径(经典 marker 先验、按丰度排名、单模态答案、无依据的因果解释)。**判分**:结构化 JSON 上的类型化检查(列表/字典匹配、字段谓词、同义词、对生物学不相容答案的 hard-fail),只判终点、不规定路径。**诊断**:作者在复现后定义"chokepoint",由 4 个 LLM 评审按 rubric 给轨迹打分,但**只作诊断,不作为基准分**。**运行**:17 个模型-harness 组合(PI、Claude Code、OpenAI Codex;Claude、Gemini、GPT、Grok、Kimi、GLM),每题 3 次重复,报告 Wilson CI 与 any/majority/all 三档稳健性。
<!-- EN --> **Organised by study system, not dataset**: each system contributes several evaluations that interrogate the same experiment from different angles (identity, state, regulation, composition, mechanism). **Paper claims are candidate sources, not automatic ground truth**: a task is kept only if its conclusion can be independently reproduced from the staged data and survives review, distractor design and inspection of trajectories from multiple model families. Each task bundles a compact question, raw/near-raw data nodes, auxiliary resources, a controlled answer surface, reproduction notes and trajectory rubrics. **Answer surfaces** use the objects analysts reason with — cell-state identities, donor compositions, regulator and direction labels, clonotype/repertoire claims, ligand–receptor interpretations, and **explicit "mechanism-caution" labels**; distractors separate data-supported conclusions from shortcuts (canonical marker priors, abundance ranking, single-modality answers, unsupported causal readings). **Grading**: typed checks over structured JSON (list/dict matching, field predicates, synonyms, hard-fails for biologically incompatible answers), endpoint-only with any valid path allowed. **Diagnostics**: authors define "chokepoints" after reproduction; four LLM judges score trajectories against rubrics, used **only as diagnostics, never as the score**. **Runs**: 17 model–harness pairs (PI, Claude Code, OpenAI Codex harnesses; Claude, Gemini, GPT, Grok, Kimi, GLM models), three replicates per task, Wilson CIs and any/majority/all robustness counts.

## 数据 / Data
<!-- ZH --> 5 个研究系统、21 题:黑色素瘤肿瘤反应性 CD8 T 细胞(5 题;10x 5′ scRNA + 配对 scTCR + 分选门元数据);CD8 RNA+ATAC 调控推断(3 题;10x Multiome);人-猴嵌合胚胎(4 题;Smart-seq2、同源基因映射、发育参考、配体-受体库);KRAS 驱动的肺肿瘤衰老(4 题;Parse Biosciences scRNA、外部衰老 signature);致死性 COVID-19 肺病理(5 题;snRNA-seq、BCR 重建、亚群 DE、免疫组化)。另有一题故意**交换两个元数据标签**(singlet 与 tumor_cluster)而保持表达与 TCR 不变,测试 agent 是否凭数据而非标签下结论。
<!-- EN --> Five systems, 21 tasks: melanoma tumour-reactive CD8 T cells (5; 10x 5′ scRNA + paired scTCR + sort-gate metadata); CD8 RNA+ATAC regulatory inference (3; 10x Multiome); human–monkey chimeric embryos (4; Smart-seq2, ortholog maps, developmental references, ligand–receptor resources); KRAS-driven lung-tumour aging (4; Parse Biosciences scRNA, external aging signatures); lethal COVID-19 lung pathology (5; snRNA-seq, BCR reconstruction, subset DE, immunohistochemistry). One task deliberately **swaps two metadata labels** (singlet and tumor_cluster) while leaving expression and TCR untouched, to test whether agents follow data rather than labels.

## 主要结果 / Key results
<!-- ZH --> **总体**:Claude Opus 4.8 / Claude Code **16/63(25.4%;Wilson 95% CI 16.3–37.3)**,Gemini 3.5 Flash / PI 14/63(22.2%),Opus 4.8 / PI 13/63(20.6%),Gemini 3.1 Pro / PI 17.5%,GPT-5.5(Codex 或 PI)15.9%,其余多在 2–11%,最低 Grok 4.3 / PI 1.6%。全部 1,068 条轨迹中只有 125 条(11.7%)通过。**稳健性**:最强组合有至少一次通过的题 8/21、多数通过 6/21、三次全过仅 **2/21**。**题目差异**:5 题无人通过;最容易的伪时间延迟题 26/51(51.0%)。**Harness 效应**:同一模型换 harness 结果改变——Opus 4.8 在 Claude Code 16 vs PI 13;GPT-5.4 在 PI 6 vs Codex 2;GPT-5.5 两边都是 10/63 但**解出的题不同**;每个配对模型有 3–6/21 题的通过数随 harness 变化。**Rubric 诊断**:4 个评审两两相关均值 0.90(最低 0.87);同一轨迹评审 SD 5.5 分、跨重复 SD 6.3 分;通过轨迹 rubric 均值 75.9% vs 失败 58.7%;与终点的相关仅 Pearson r=0.29、Spearman ρ=0.30、AUC 0.77;最高 rubric 十分位里也只有 47/106 通过——**rubric 分高不等于结论对**。**失败模式**:(1) 熟悉的生物学先验掩盖任务证据(把 CD39/PD-1 高的单细胞当作最具肿瘤反应性,忽略物理结合 + 克隆扩增证据;标签互换题中把结果"改回"预期生物学);(2) 把原始丰度当重要性(嵌合体配体-受体题仅 2/50 通过,GPT-5.5 与 Opus 4.8 共 0/6);(3) 把关联当机制(肿瘤-T 细胞结合体题**无人通过**——免疫应答程序对去污染敏感、方向不可定,模型却给出方向性机制);(4) 不整合多模态(KLF2 题只看 RNA DE 提名 S1pr5、Cd160,或从 Klf2 RNA 而非其靶基因协同行为推断活性)。
<!-- EN --> **Overall**: Claude Opus 4.8 / Claude Code **16/63 (25.4%; Wilson 95% CI 16.3–37.3)**, Gemini 3.5 Flash / PI 14/63 (22.2%), Opus 4.8 / PI 13/63 (20.6%), Gemini 3.1 Pro / PI 17.5%, GPT-5.5 (Codex or PI) 15.9%, most others 2–11%, lowest Grok 4.3 / PI 1.6%. Only 125 of 1,068 trajectories (11.7%) pass. **Robustness**: the best pair has any-pass on 8/21 tasks, majority-pass on 6/21 and all-three-pass on only **2/21**. **Task spread**: 5 tasks have zero passes; the easiest (a pseudotime-delay task) is 26/51 (51.0%). **Harness effects**: same model, different harness, different results — Opus 4.8 16 (Claude Code) vs. 13 (PI); GPT-5.4 6 (PI) vs. 2 (Codex); GPT-5.5 10/63 under both but **solves different tasks**; 3–6 of 21 tasks change pass count per paired model. **Rubric diagnostics**: mean pairwise judge correlation 0.90 (min 0.87); judge SD 5.5 points per trajectory vs. replicate SD 6.3; passing trajectories average 75.9% rubric vs. 58.7% for failing; association with the endpoint is only Pearson r=0.29, Spearman ρ=0.30, AUC 0.77, and the top rubric decile holds just 47/106 passes — **high rubric scores do not mean correct conclusions**. **Failure modes**: (1) familiar priors masking task evidence (treating CD39/PD-1-high singlets as most tumour-reactive, ignoring physical engagement + clonal expansion; in the label-swap task, "relabelling back" to expected biology); (2) raw abundance mistaken for importance (chimera ligand–receptor task: 2/50 passes; GPT-5.5 and Opus 4.8 0/6); (3) association mistaken for mechanism (tumour–T-cell conjugate task: **no pair passes** — the immune-response programme is decontamination-sensitive and directionally undetermined, yet models assert a directional mechanism); (4) failure to integrate modalities (KLF2 tasks: nominating S1pr5 or Cd160 from RNA DE alone, or inferring KLF2 activity from Klf2 RNA rather than coordinated target behaviour).

## 创新点 / Contributions
- <!-- ZH --> **声明条件化的长程可验证基准**:论文声明 → 独立复现 → 受控答案面 + 捷径干扰项,解决"长程任务没有可判真值"的问题。 <!-- EN --> **A claim-conditioned, verifiable long-horizon benchmark**: paper claim → independent reproduction → controlled answer surface + shortcut distractors, addressing the "no gradable truth for long tasks" problem.
- <!-- ZH --> 显式的**"机制需谨慎"答案标签**——把"不该下因果结论"本身变成可判分的正确答案。 <!-- EN --> Explicit **"mechanism-caution" answer labels** — making "do not draw a causal conclusion" itself a gradable correct answer.
- <!-- ZH --> 数据扰动探针(元数据标签互换),检验 agent 是凭数据还是凭标签。 <!-- EN --> A data-perturbation probe (metadata label swap) testing whether agents follow data or labels.
- <!-- ZH --> 量化证明 **rubric/LLM 评审分 ≠ 正确性**(AUC 0.77),并量化 harness 效应——agent 评测应以"模型 + harness"为单位。 <!-- EN --> Quantitative evidence that **rubric/LLM-judge scores ≠ correctness** (AUC 0.77), and a quantified harness effect — agents should be evaluated as model + harness.
- <!-- ZH --> 一份具体的单细胞科学推理失败分类(先验替代证据、丰度当重要性、关联当机制、单模态推断)。 <!-- EN --> A concrete taxonomy of single-cell reasoning failures (priors over evidence, abundance as importance, association as mechanism, single-modality inference).

## 局限 / Limitations
- <!-- ZH --> 规模小:21 题、5 个系统,每个组合每题 3 次;Wilson CI 很宽(16–37%),组合间差异多不显著。 <!-- EN --> Small: 21 tasks, 5 systems, 3 replicates per pair per task; Wilson CIs are wide (16–37%) and most pairwise differences are not significant.
- <!-- ZH --> 确定性终点判分会惩罚预设答案面之外的合理声明(作者承认);rubric 依赖 prompt 与评审模型。 <!-- EN --> Deterministic endpoint grading penalises valid claims outside the pre-specified surface (acknowledged); rubrics are prompt- and judge-dependent.
- <!-- ZH --> 文中未给出代码、题目或轨迹的公开链接,外部难以复现;作者为 LatchBio(提供生物信息平台的公司)。 <!-- EN --> No public link to code, tasks or trajectories is given, so external reproduction is hard; authors are at LatchBio (a bioinformatics-platform company).
- <!-- ZH --> 没有空间组学或组织学模态;没有校准/置信度维度——只问"对不对",不问"agent 知不知道自己可能错"。 <!-- EN --> No spatial or histology modality; no calibration/confidence dimension — it asks "right or wrong," not "does the agent know it might be wrong."

## 与本研究方向的关系 / Relation to our direction
<!-- ZH --> 这是本批中对 **Agent 可信度课题最核心**的一篇,几乎是 Agent 可信度课题的"上游证据":**(1) 声明级评估**——它评的不是步骤而是"这个结论是否被数据支持",与我们的 claim-to-evidence verification 是同一对象;它的"论文声明只作候选、须独立复现才入库"流程,可以直接用于构造肾脏版声明集(取 KPMP/Lake/DKD 图谱论文中的结论,在我们能拿到的数据上复现后入库)。**(2) 失败分类**——"先验替代证据 / 丰度当重要性 / 关联当机制 / 单模态推断"四类,可作为我们组学特有失败分类的起点,肾脏场景再加上环境 RNA 与批次被当作生物信号、snRNA 与 Xenium 不一致时只信一方、把损伤 marker 当因果驱动等。**(3) rubric 分不等于正确性(AUC 0.77)**——直接支持 Agent 可信度课题的立论:需要一个**校准过的** verifier,而不是再加一个 LLM 评审;评审间高一致(0.90)而与真值弱相关,说明"多评审一致"不是可靠性的代理。**(4) 重复与 harness**——最强组合三次全过仅 2/21,同模型换 harness 解出不同题,正是 Agent 可信度课题 "rerun stability"要量化的现象,也提醒 AIRIS WP3 / MLCommons 式的报告应以"模型 + harness"为单位并给出 any/majority/all 三档。对 **伪影注入课题**,KLF2 题的教训(只看 RNA 会选错调控因子,需 chromatin 支持)与我们"跨模态一致性区分伪影与疾病"的思路同源:snRNA 上的异常若在 snATAC/Xenium 上得不到支持,应降低置信度。
<!-- EN --> This is the paper in this batch **most central to the agent-trustworthiness topic** — essentially its upstream evidence. **(1) Claim-level evaluation**: it scores not steps but "is this conclusion supported by the data," the same object as our claim-to-evidence verification; its "paper claims are candidates only and must be independently reproduced" pipeline can build a kidney claim set directly (take conclusions from KPMP/Lake/DKD-atlas papers, reproduce them on data we can access, then admit them). **(2) Failure taxonomy**: "priors over evidence / abundance as importance / association as mechanism / single-modality inference" is a starting point for our omics-specific taxonomy, to which kidney adds ambient RNA and batch read as biology, trusting one side when snRNA and Xenium disagree, and treating injury markers as causal drivers. **(3) Rubric score ≠ correctness (AUC 0.77)**: direct support for the agent-trustworthiness topic's premise that a **calibrated** verifier is needed rather than another LLM judge; high inter-judge agreement (0.90) with weak correlation to truth shows that "judges agree" is not a proxy for reliability. **(4) Replicates and harnesses**: the best pair passes all three replicates on only 2/21 tasks and the same model solves different tasks under different harnesses — exactly the "rerun stability" the agent-trustworthiness topic wants to quantify, and a reminder that AIRIS WP3 / MLCommons-style reporting should use model + harness as the unit with any/majority/all counts. For **the artifact-injection topic**, the KLF2 lesson (RNA alone picks the wrong regulator; chromatin support is needed) shares the logic of using cross-modal agreement to separate artifact from disease: an snRNA anomaly unsupported in snATAC/Xenium should lose confidence.
