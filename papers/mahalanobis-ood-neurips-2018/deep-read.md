## 一句话 / One-liner
<!-- ZH --> 不重新训练任何预训练 softmax 分类器,在它的特征空间里为每一类拟合**共享协方差的类条件高斯**(即 GDA/LDA),用测试样本到最近类均值的 **Mahalanobis 距离**作为置信分数;再加上输入预处理与多层特征集成,同一个分数同时在 OOD 检测和对抗样本检测上达到当时最优,对噪声标签和小样本训练集更稳健,还能免训练地做类增量学习。
<!-- EN --> Without retraining a pre-trained softmax classifier, fit **class-conditional Gaussians with a tied covariance** (GDA/LDA) in its feature space and use the **Mahalanobis distance** of a test sample to the closest class mean as the confidence score; with input pre-processing and a multi-layer feature ensemble, the same score reached state of the art on both OOD and adversarial-sample detection, was more robust to noisy labels and small training sets, and enabled training-free class-incremental learning.

## 研究问题 / Problem
<!-- ZH --> softmax 分类器对异常样本(统计上远离训练分布的 OOD 样本,或对抗样本)也给出过度自信的后验。此前的方法要么只针对 OOD(MSP 基线、ODIN 用输出层置信度),要么只针对对抗样本(核密度 KD+PU、LID),没有一个**通用检测器**两者都做得好。此外 ODIN 的超参要用 OOD 验证集调,而实际中 OOD 样本事先不可得。
<!-- EN --> Softmax classifiers produce overconfident posteriors even for abnormal samples — statistically far OOD inputs or adversarial ones. Prior detectors targeted only OOD (the MSP baseline and ODIN, both using output-layer confidence) or only adversarial samples (kernel density KD+PU, LID); no **universal detector** worked well on both. ODIN also tunes its hyperparameters on OOD validation data, which is usually unavailable in advance.

## 方法 / Method
<!-- ZH --> **从 softmax 到生成式分类器**:在 GDA 下,共享协方差的类条件高斯所诱导的后验与 softmax 分类器等价,因此预训练特征 f(x) 可能近似服从类条件高斯。用训练集估计经验类均值 μ̂_c 与共享协方差 Σ̂(即最大似然拟合)。**分数**:M(x) = max_c −(f(x)−μ̂_c)ᵀ Σ̂⁻¹ (f(x)−μ̂_c),对应测试样本对数密度。作者先验证:用 Mahalanobis 距离分类的准确率与 softmax 相当(打破「生成式分类器一定差于判别式」的常识),且 Mahalanobis 分数在 ResNet/CIFAR-10 vs TinyImageNet 上优于 Euclidean 距离和 MSP。**校准技巧**:(1) **输入预处理**——沿增大 M(x) 的方向给输入加小扰动 x̂ = x − ε·sign(∇ₓ距离),与 ODIN 类似但优化的是 Mahalanobis 分数;(2) **特征集成**——在每个 dense/residual block 末端提特征(通道维平均池化 F×H×W → F×1),各自算 M_ℓ,再用**逻辑回归**学权重 α_ℓ 加权求和;低层特征对 LSUN、TinyImageNet、DeepFool 往往更有效。超参(ε、α_ℓ)可用每对 ID/OOD 各 1000 张的验证集调,也可**只用 ID 样本 + FGSM 生成的对抗样本**来调(不需要任何 OOD 数据)。**类增量学习**:新类到来时只需计算其均值并更新共享协方差 Σ̂ ← C/(C+1)·Σ̂ + 1/(C+1)·Σ̂_{C+1},无需重训。
<!-- EN --> **From softmax to a generative classifier**: under GDA, the posterior induced by class-conditional Gaussians with a tied covariance is equivalent to a softmax classifier, so pre-trained features f(x) may approximately follow class-conditional Gaussians. Empirical class means μ̂_c and the tied covariance Σ̂ are estimated from training data (the MLE fit). **Score**: M(x) = max_c −(f(x)−μ̂_c)ᵀ Σ̂⁻¹ (f(x)−μ̂_c), i.e. the log-density of the test sample. The authors first check that a Mahalanobis-distance classifier matches softmax accuracy (contrary to the belief that generative classifiers must be worse) and that the Mahalanobis score beats Euclidean distance and MSP on ResNet/CIFAR-10 vs TinyImageNet. **Calibration techniques**: (1) **input pre-processing** — perturb the input in the direction that increases M(x), x̂ = x − ε·sign(∇ₓ distance), like ODIN but on the Mahalanobis score; (2) **feature ensemble** — extract features at the end of every dense/residual block (average-pooled F×H×W → F×1), compute M_ℓ per layer and combine with weights α_ℓ learned by **logistic regression**; low-level features are often better for LSUN, TinyImageNet and DeepFool. Hyperparameters (ε, α_ℓ) are tuned on a validation set of 1,000 images per ID/OOD pair, or **using only ID samples plus FGSM adversarial samples** (no OOD data at all). **Class-incremental learning**: a new class just adds its mean and updates the tied covariance Σ̂ ← C/(C+1)·Σ̂ + 1/(C+1)·Σ̂_{C+1}, with no retraining.

## 方法谱系 / Method lineage
<!-- ZH --> **范式:特征嵌入 + 密度(feature-embedding density / one-class 的参数化形式)**,同时属于 post-hoc 的 OOD 检测。它建立在 MSP 基线(`msp-ood-iclr-2017`,文中 [13])与 ODIN(输入预处理思想)之上,并把对抗检测里用特征密度的 KD+PU、LID(只用 Euclidean)推进到 Mahalanobis。**后续影响**:PaDiM(`padim-icpr-2020`)明确写「受 [23]、[26] 启发,我们用 Mahalanobis 距离」给每个 patch 位置打分,[26] 即本文——把这一思路从图像级 OOD 搬到工业图像的**像素级异常定位**,并进一步建模跨层相关;energy score(`energy-ood-neurips-2020`)把它作为对比基线;OpenOOD/综述(`generalized-ood-survey-ijcv-2024`)把它列为 distance-based 代表(MDS),并指出它在 MNIST 上好、在 CIFAR 上差,而非参数的 KNN 更通用。
<!-- EN --> **Paradigm: feature-embedding density (a parametric one-class model)**, used as post-hoc OOD detection. It builds on the MSP baseline (`msp-ood-iclr-2017`, ref [13]) and ODIN (input pre-processing), and upgrades the feature-density adversarial detectors KD+PU and LID (Euclidean only) to Mahalanobis. **What it led to**: PaDiM (`padim-icpr-2020`) states "Inspired by [23], [26], we use the Mahalanobis distance" to score each patch position, with [26] being this paper — moving the idea from image-level OOD to **pixel-level industrial anomaly localization** and additionally modelling cross-layer correlations; the energy score (`energy-ood-neurips-2020`) uses it as a baseline; OpenOOD / the survey (`generalized-ood-survey-ijcv-2024`) list it as the distance-based representative (MDS), noting it does well on MNIST but poorly on CIFAR, while non-parametric KNN generalizes better.

## 数据 / Data
<!-- ZH --> 分类器:DenseNet-100 与 ResNet-34,训练于 CIFAR-10、CIFAR-100、SVHN。OOD 测试:在其余数据集之间互换,外加 TinyImageNet(ImageNet 子集,10,000 张测试图,200 类)与 LSUN(10,000 张测试图,10 个场景),降采样到 32×32。对抗攻击:FGSM、BIM、DeepFool、CW。类增量学习:ResNet-34,CIFAR-100 → 下采样 ImageNet(以及附录中 CIFAR-100 → CIFAR-10)。
<!-- EN --> Classifiers: DenseNet-100 and ResNet-34 trained on CIFAR-10, CIFAR-100 and SVHN. OOD tests: the other datasets, plus TinyImageNet (ImageNet subset, 10,000 test images, 200 classes) and LSUN (10,000 test images, 10 scenes), downsampled to 32×32. Adversarial attacks: FGSM, BIM, DeepFool, CW. Class-incremental learning: ResNet-34 with CIFAR-100 → downsampled ImageNet (and CIFAR-100 → CIFAR-10 in the appendix).

## 主要结果 / Key results
<!-- ZH --> - **消融**(ResNet / CIFAR-10 vs SVHN,TNR@TPR95):MSP 基线 32.47、ODIN 86.55;Mahalanobis 不加任何技巧 54.51(AUROC 93.92),加上输入预处理 + 特征集成 96.42(AUROC 99.14,AUPR-out 99.60)。
- **OOD 全表**(以 OOD 验证集调参):所有 ID/OOD 组合都优于 MSP 与 ODIN。例如 DenseNet / CIFAR-100 vs LSUN 的 TNR@TPR95:MSP 16.7 / ODIN 41.2 / Mahalanobis 91.4;ResNet / CIFAR-100 vs LSUN:18.8 / 45.6 / 90.9(摘要中「45.6% → 90.9%」);DenseNet / CIFAR-10 vs SVHN 的 AUROC 89.9 / 95.5 / 98.1。
- **不用 OOD 数据调参**(只用 ID + FGSM):Mahalanobis 仍一致优于两者,甚至超过用 OOD 调参的 ODIN;而 ODIN 在某些情况下(如 SVHN 上的 DenseNet)反而不如基线。但 ResNet / CIFAR-100 上掉得明显(如 vs SVHN 的 TNR 41.9)。
- **对抗检测**:相对 LID,ResNet / CIFAR-10 上 CW 的 TNR 从 82.9% 提到 95.8%;只用 FGSM 调参也能检出未见过的 BIM、DeepFool、CW。
- **稳健性**:训练数据很少或带随机标签(最多 40%)时,Mahalanobis 的 AUROC 保持较高,MSP 与 ODIN 明显下降。
- **类增量学习**:所有新类加入后,AUC 40.0%(第二场景 22.1%),优于微调 softmax 的 32.7%(15.6%)和 Euclidean 分类器的 32.9%(17.1%)。
<!-- EN --> - **Ablation** (ResNet / CIFAR-10 vs SVHN, TNR@TPR95): MSP baseline 32.47, ODIN 86.55; plain Mahalanobis 54.51 (AUROC 93.92); with input pre-processing + feature ensemble 96.42 (AUROC 99.14, AUPR-out 99.60).
- **Full OOD table** (tuned on OOD validation): beats MSP and ODIN in every ID/OOD pair. E.g. DenseNet / CIFAR-100 vs LSUN TNR@TPR95: MSP 16.7 / ODIN 41.2 / Mahalanobis 91.4; ResNet / CIFAR-100 vs LSUN: 18.8 / 45.6 / 90.9 (the abstract's "45.6% → 90.9%"); DenseNet / CIFAR-10 vs SVHN AUROC 89.9 / 95.5 / 98.1.
- **Tuning without OOD data** (ID + FGSM only): Mahalanobis still beats both consistently, even beating OOD-tuned ODIN, while ODIN sometimes falls below the baseline (e.g. DenseNet on SVHN). It degrades noticeably on ResNet / CIFAR-100 (e.g. TNR 41.9 vs SVHN).
- **Adversarial detection**: vs LID, CW TNR rises from 82.9% to 95.8% on ResNet / CIFAR-10; tuning only on FGSM still detects unseen BIM, DeepFool and CW.
- **Robustness**: with few training samples or up to 40% random labels, Mahalanobis AUROC stays high while MSP and ODIN drop.
- **Class-incremental**: after all new classes, AUC 40.0% (22.1% in the second scenario) vs 32.7% (15.6%) for a fine-tuned softmax and 32.9% (17.1%) for a Euclidean classifier.

## 创新点 / Contributions
<!-- ZH --> (1) 用 GDA–softmax 等价性为「在特征空间做类条件高斯密度」提供理论动机,并实证生成式分类器不损准确率;(2) 一个分数统一处理 OOD 与对抗样本;(3) 多层特征集成(低层特征往往更敏感);(4) 演示可以不用 OOD 数据、只用合成扰动样本调参;(5) 免训练类增量学习——只更新均值与共享协方差。
<!-- EN --> (1) Motivates class-conditional Gaussian density in feature space via the GDA–softmax equivalence and shows the generative classifier loses no accuracy; (2) one score for both OOD and adversarial samples; (3) a multi-layer feature ensemble (low-level features are often more sensitive); (4) shows hyperparameters can be tuned without OOD data, using synthetic perturbations; (5) training-free class-incremental learning by updating means and the tied covariance.

## 局限 / Limitations
<!-- ZH --> 共享协方差的高斯假设是强假设,类内分布多峰或各类方差差异大时不成立;最好结果依赖用 OOD 验证样本训练逻辑回归权重——作者给出的 FGSM 替代方案在 CIFAR-100/ResNet 上掉点明显;输入预处理需要对输入求梯度,测试时多一次前后向;所有实验是 32×32 小图;后来 OpenOOD 发现它在 CIFAR 近 OOD 上不如更晚的方法(见综述)。需要有标签的分类器(类均值)。
<!-- EN --> The tied-covariance Gaussian is a strong assumption that fails for multi-modal classes or very different per-class variances; the best numbers rely on logistic-regression weights fit with OOD validation samples, and the FGSM substitute degrades on CIFAR-100/ResNet; input pre-processing needs an input gradient (an extra forward/backward at test time); all experiments use 32×32 images; OpenOOD later found it weaker than newer methods on CIFAR near-OOD (see the survey). It needs a labelled classifier (class means).

## 与本研究方向的关系 / Relation to our direction
<!-- ZH --> **这是课题 1 最自然的 detect 基线之一**。映射:样本 = 细胞(或 spot、H&E patch);特征空间 = scVI/scANVI latent、单细胞基础模型嵌入,或 H&E 病理基础模型(UNI、Virchow)的 patch 嵌入;「类」= 健康参照(KPMP、Lake 图谱、HuBMAP 正常肾)里的细胞类型;对每个细胞类型拟合均值与(共享)协方差,用到最近类型的 Mahalanobis 距离作为异常分——在 snRNA latent 和 snATAC latent 上**各算一次**,两者都高 → 更可能是疾病,只有一个高 → 更可能是 artifact,这正好是课题 1 跨模态一致性的打分方式。类增量算法也直接有用:专家确认一个新的损伤状态(如 aPT)后,把它作为新「正常类」加入参照,只需算均值与更新协方差,适合迭代构建 KidneyAnomalyBench。**哪些假设会断**:(1) **批次效应**——新 donor 或新平台的整体平移会让所有细胞的距离都升高,距离被 batch 主导;必须在整合后的 latent 上算,而 `refmap-eval-biorxiv-2025`(mapQC)正是用参照自身的样本间差异做零分布来处理这一点;(2) **共享协方差**不适合肾脏——PT 与免疫细胞的方差结构差别很大,需要按类型的协方差(QDA)或收缩估计,而稀有类型(如 MD、podocyte)细胞数少,协方差病态;(3) **doublet** 落在两个类均值之间,距离中等,可能漏报也可能误报;**环境 RNA** 把所有细胞往 soup 方向推,形成系统偏移;**分割错误**(Xenium)把邻居转录本混进来,同样形成「混合」嵌入;(4) **连续疾病状态**让「最近类」概念模糊;(5) 输入预处理需要对输入求梯度,对计数数据或冻结的基础模型嵌入不太适用;(6) 特征集成的权重要用 OOD 验证集学——肾脏里没有现成的 OOD 集;用合成扰动(作者用 FGSM)替代时要小心:若用模拟 doublet 或注入环境 RNA 调参,会**教检测器去找 artifact**。**仓库中已有的同类做法**:`padim-icpr-2020` 明确受本文启发,在每个 patch 位置用 Mahalanobis 距离做像素级异常定位(H&E patch 的直接模板);`kidney-multimodal-genomebiol-2026` 用 Mahalanobis 距离衡量整合后细胞群之间的分离度(用作整合指标,不是异常检测);`histo-anomaly-bi-repo` 在健康组织深度特征上拟合 one-class SVM、`histo-nejmai-2024` 在 CTransPath 特征上用改良 kNN——都是同一「健康特征空间中的距离/密度」家族;`healthy-ref-natgenet-2023` 和 `refmap-eval-biorxiv-2025` 在 scVI latent 中相对健康参照做邻域级比较。**对课题 2**:一个可调用、确定性的 Mahalanobis 打分工具适合测 agent 的重跑稳定性,并检查 agent 是否说明了它依赖的高斯/共享协方差假设。
<!-- EN --> **One of the most natural Topic-1 detect baselines.** Mapping: samples = cells (or spots, H&E patches); feature space = the scVI/scANVI latent, a single-cell foundation-model embedding, or a pathology foundation model's patch embedding (UNI, Virchow); "classes" = cell types in a healthy reference (KPMP, the Lake atlas, HuBMAP normal kidney). Fit a mean and (tied) covariance per cell type and use the Mahalanobis distance to the nearest type as the anomaly score — **once on the snRNA latent and once on the snATAC latent**: both high → more likely disease, only one high → more likely artifact, which is exactly how Topic 1's cross-modal agreement can be scored. The class-incremental update is also useful: once experts confirm a new injury state (e.g. aPT), add it to the reference as a new "normal" class by computing its mean and updating the covariance — a fit for iteratively building KidneyAnomalyBench. **Which assumptions break**: (1) **batch effects** — a global shift for a new donor or platform raises every cell's distance, so the score becomes batch-dominated; it must run on an integrated latent, and `refmap-eval-biorxiv-2025` (mapQC) handles exactly this by using the reference's own inter-sample variation as a null; (2) a **tied covariance** fits the kidney poorly — PT and immune cells have very different variance structure, calling for per-type covariances (QDA) or shrinkage, while rare types (e.g. MD, podocytes) have few cells and ill-conditioned covariances; (3) **doublets** fall between two class means at moderate distance and can be missed or mis-flagged; **ambient RNA** pushes all cells toward the soup profile, a systematic shift; **segmentation errors** (Xenium) blend neighbours' transcripts into "mixed" embeddings too; (4) **continuous disease states** blur "nearest class"; (5) input pre-processing needs an input gradient, which suits count data or frozen foundation-model embeddings poorly; (6) the ensemble weights are learned on an OOD validation set that the kidney setting does not have; substituting synthetic perturbations (the authors use FGSM) needs care — tuning on simulated doublets or injected ambient RNA would **teach the detector to find artifacts**. **Repo papers already in this family**: `padim-icpr-2020` is explicitly inspired by this paper and uses Mahalanobis distance per patch position for pixel-level localization (a direct template for H&E patches); `kidney-multimodal-genomebiol-2026` uses Mahalanobis distance to measure separation between integrated cell populations (as an integration metric, not anomaly detection); `histo-anomaly-bi-repo` fits a one-class SVM on healthy-tissue deep features and `histo-nejmai-2024` scores CTransPath features with a modified kNN — the same "distance/density in a healthy feature space" family; `healthy-ref-natgenet-2023` and `refmap-eval-biorxiv-2025` do neighbourhood-level comparisons against a healthy reference in the scVI latent. **For Topic 2**: a callable, deterministic Mahalanobis scorer is a good tool for testing agent rerun stability and checking whether an agent states the Gaussian / tied-covariance assumption it relies on.
